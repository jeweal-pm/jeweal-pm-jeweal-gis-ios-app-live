# Edit: Organization / Store sheet and "No Stores Found" sheet

## What changed and why
- **Dim background fades instead of sliding.** The Organization/Store overlay used a
  `CATransition` push that moved the whole overlay (including the translucent black
  background). It now fades the dim colour and slides only the white sheet
  (`showStoreContentView` / `dismissStoreContentView` in `LoginController.swift`).
- **Building button can't re-open the sheet.** The button sits above the overlay, so a second
  tap reloaded organizations and presented the sheet again. `didTapOrganizationButton` now
  returns early while the sheet is visible or animating (`canPresentStoreSheet`).
- **"No Stores Found" slides up instead of cross-dissolving.** The controller is presented
  without the system transition; its dim view fades in and its sheet slides up (and the
  reverse when closed).
- **"No Stores Found" sheet height matches the design (`Setup 7.png`, 375x812).** The sheet top
  sits 25pt below the safe-area top (72pt on the 812pt design) instead of 62% of the screen
  height; content is pinned to the bottom like the design.
- **Store icon uses the UX/UI asset** `building-storefront` from the design zip, added as
  `GIS/Assets.xcassets/building_storefront.imageset` (SF Symbol is kept as a fallback).

  24pt from each side) and the player uses aspect-fit, so the whole frame is shown.

- Offscreen check at 375x812 / 430x881 / 430x932 / 375x667 / 768x1024: every box is 3:4; border position and corner profile match

  and Save" at 812pt) instead of being full width and cropped.
