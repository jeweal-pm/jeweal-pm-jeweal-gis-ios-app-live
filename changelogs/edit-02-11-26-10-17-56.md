# Edit: KYC status banner on Customer Profile

## What changed and why
Figma "POS > Customer > Profile" shows the customer's KYC state under the header. Added:
- A banner above the profile info card for 5 states (not verified, rejected, expired, in progress, approved). Not verified / rejected / expired also show a "Verify" button.
- A verified shield after the name when KYC is completed (no banner).
- `kycStatus` is passed from the Customer list rows (PosCustomerSearch, CustomerSearch) and also read from the `App/customer/get` response when present. If the API sends no `kycStatus`, no banner is shown.
- "pending" from the API is treated as In Progress; an empty value means not verified.

## Files touched
- GIS/Extras/CustomerProfile.swift (banner logic, `KycProfileBanner`, `KycProfileBannerView`)
- GIS/Pos/PosCustomerSearch.swift, GIS/Extras/CustomerSearch.swift (pass `kycStatus` to the profile)
- GIS/DynamicViews/{en,th,zh-Hans,ja,ar,ru}.lproj/Localization.strings (8 new strings)
- GIS/GISTests/KycProfileBannerTests.swift (new)

## Before / after
Before: Profile had no KYC information. After: banner/shield per KYC state as in the design.
